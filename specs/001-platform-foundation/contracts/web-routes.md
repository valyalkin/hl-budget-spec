# Contract: hl-budget-frontend routes

**Feature**: `001-platform-foundation` | Served by the Next.js app at `/` on the shared host.
Everything under `/api` goes to `hl-budget-backend` (Traefik, prefix not stripped).

## Pages

| Path | Access | Renders | Metadata | Spec |
|---|---|---|---|---|
| `/` | Public | Landing: "HL Budget", one-line description, **Sign in** (`<a href="/auth/login">`, no prefetch). With a session: **Go to HL Budget** → `/home`. With `?signin=failed`: an `aria-live` notice "Sign-in did not complete. You can try again." | `title: "HL Budget"`, indexable, in `sitemap.ts` | FR-001, FR-006, US1-AS1, edge "signed-in user opens landing" |
| `/home` | Protected | Header with app name + **Sign out** (`<a href="/auth/logout">`); greeting with name/email/avatar from `PUT /api/v1/users/me`; skeleton while loading; error boundary "Something went wrong" + **Try again** | `title: "Home · HL Budget"`, `robots: { index: false, follow: false }` | FR-009, FR-011, FR-021, US1-AS3, US4-AS4/5 |
| any unknown path | Public | Not-found page with a link to `/` | `title: "Not found · HL Budget"`, `robots: noindex` | FR-022, US4-AS6 |

`robots.ts` disallows `/home` and `/auth/`; `sitemap.ts` lists only `/` (FR-004, Principle III).

## SDK-served routes (no page files; mounted by `proxy.ts`)

| Path | Behaviour |
|---|---|
| `/auth/login?returnTo=<relative path>` | Starts Universal Login with `audience` + `openid profile email offline_access` |
| `/auth/callback` | Completes login. `onCallback`: on error → `/?signin=failed`; on success → `returnTo` if it is a same-origin relative path, else `/home` |
| `/auth/logout` | Clears the session cookie, ends the Auth0 session, returns to `/` |

`/auth/profile` and `/auth/access-token` are **disabled** (`enableAccessTokenEndpoint: false`)
so no token or profile is ever readable by browser JavaScript (FR-007).

## Operational routes (route handlers, excluded from the proxy matcher)

| Path | Response |
|---|---|
| `GET /healthz` | `200 {"status":"UP"}`, no dependency checks |
| `GET /readyz` | `200 {"status":"UP"}` (the web app has no required dependency, research R-008) |

## Gating rules (`proxy.ts`)

- `PROTECTED_PREFIXES = ['/home']`. Without a session → `302 /auth/login?returnTo=<path+query>`
  and no page content (FR-002, US2-AS1).
- Every pass-through returns the SDK's response so the rolling session cookie is refreshed.
- Protected responses carry `Cache-Control: private, no-cache, no-store` (US3-AS4).
- Matcher excludes `_next/static`, `_next/image`, `favicon.ico`, `robots.txt`, `sitemap.xml`,
  `healthz`, `readyz`.

## Backend call made by the web app

| Caller | Request | 2xx | 401 | other / timeout |
|---|---|---|---|---|
| `ensureMyProfile()` in `app/lib/data.ts` | `PUT {API_BASE_URL}/api/v1/users/me`, `Authorization: Bearer <access token>` (server-side only) | Render profile (200 and 201 treated the same) | Redirect to `/auth/login?returnTo=/home` (FR-010, US4-AS3) | Throw → `app/home/error.tsx` (FR-021) |

Types come from `app/lib/api-schema.d.ts`, generated by `pnpm generate:api` from
`contracts/api.yaml` copied from `hl-budget-backend` (Principle II). Never hand-written.

## Security headers (all responses)

`Content-Security-Policy` (self, `img-src` self + `https:` for avatars + `data:`),
`X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`,
`X-Frame-Options: DENY`, `Strict-Transport-Security` (TLS terminates at Traefik; the browser
always sees HTTPS). From the `frontend-developer` skill's `tooling.md` "Security headers".
